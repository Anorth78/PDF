Webex Control Hub Migration Tool Considerations
1. Looking for Jabber and Webex App usage & insights before/during/after the 
migration?
• Deploy CCUC1
• Optionally deploy Jabber Telemetry 
2. Is Director Connector, Azure AD or SCIM deployed to sync users to Control Hub?
• The ‘User/Contact Synchronization’ tool is not applicable for users, but can still be used for 
Org Contacts
3. Planning a phased user migration?
• Use the ‘Migrate Jabber to the new Webex’ Control Hub tool
4. How are user contacts being migrated?
• By End-user ➔ Use Jabber XML file to enable end-users to migrate their own Jabber 
contacts/preferences
• By Admin ➔ Use the ‘Migrate Personal Contacts to Webex App’ Control Hub tool to migrate 
end-users’ Jabber contacts for them (users must configure their own preferences in the Webex App)
1 Required for the ‘Migrate Jabber to the new Webex’, 
‘Migration Insights’, and ‘User/Contact Synchronization’ tools
