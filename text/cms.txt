Call Bridge vs. Call Bridge Cluster vs. Call Bridge Groups
BRKCOL-2228
• Call Bridge
Connects and bridges multiple participants into their meetings. It doesn‘t
offer load balancing or resiliency
• Call Bridge Cluster
Enables and allows you to operate multiple Call Bridges as a single entity
and scale capacity beyond of a single Call Bridge
• Call Bridge Group
Is a subset of clustered Call Bridges (CB) to allow logical grouping of
CBs which are located closely to each other (same site, DC, etc.) and to
enable better ressource allocation and load balancing

--- PAGE 25 ---
© 2026 Cisco and/or its affiliates. All rights reserved.
Call Bridge Resiliency
BRKCOL-2228
• Resiliency ≠ Load Balancing
• In a Call Bridge Cluster, if a Call Bridge fails the call will immediately
failover to the next available callbridge
• A CB Cluster should contain at least 3 nodes up to 7 nodes
(recommended)
Up to 24 nodes are possible, Cisco approval needed
• Node RTT between cluster nodes should not exeed 300ms
• All nodes are connected to the same Database/ DB Cluster

BRKCOL-2228

ability to adjust gain (+/-) for each
participant

audio stream received from the
participant, and so affects how loud they
sound to other conference participants
Allowed Gains:
+6 dB = Actual volume * 4
+3 dB = Actual volume * 2
0 dB = Automatic Gain (CMS default)
-3 dB = Actual volume / 2
+6 dB = Actual volume / 4
