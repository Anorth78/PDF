--- PAGE 30 ---
Performance considerations
Impact of cloud connectors on UC infrastructure nodes
CPU and memory (RAM) usage
The CCUC service runs with low priority. This 
helps in restricting the service to minimize CPU 
usage. The service runs with approximately 345 
MB of RAM. The CPU usage is 12%.
Buffer size calculation details in documentation
Disk Space Usage
Installed, the CCUC service takes about 155 MB 
of disk space for Voice Operating System (VOS) 
based products, such as Unified CM and IM & 
Presence. The space requirement for telemetry 
service is 3 MB for executables.
For log files, 10 MB in the /var/log/active folder 
path.
Bandwidth usage
For a larger cluster, ensure that you have at least 
2 Mbps of bandwidth to the cloud.
Call Detail Recording (CDR) and Call 
Management Recording (CMR)
Must be enabled in UCM (service parameter 
“CDR Enabled Flag” and “Call Diagnostics 
Enabled” )
To avoid delays or error in Webex Cloud-
Connected UC analysis and operations, we 
recommend that you set CDR File Time Interval 
to 1.
