Learnings from Partners Cisco Cloud control onboarding 
• Partners consistently view Cloud Control as a promising, well-designed unifying platform - cross-launch and global 
inventory/topology are standout strengths (WWT; Computacenter fully committed to the vision).
• AI Canvas is showing real utility - it solved an actual network bug for Accenture, and there is strong interest in agentic 
ops (NTT building custom agents; CDW and WWT into Studio alpha).
• Partners are Cisco Cloud control studio with Agent / APP builders is a great opportunity for the ecosystem and Agentic 
workflow automation 
• Need to update Ideal partner profile with minimum 3+ domains 
• Documentation on product capabilities , integration and supported platforms 
• Clarity on Customer engagement through partners, partner entitlements on domain controllers 
• Concept of single super admin / read only access is a big operating model change for partners & customers.
