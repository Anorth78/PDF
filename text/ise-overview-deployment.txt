High Availability and Failover Mechanisms
• PAN HA: Primary and Secondary PAN setup for 
administrative redundancy
• PAN Failover: Automatic failover is configurable 
but disabled by default (3 nodes mandatory)
• MnT HA: Primary and Secondary MnT nodes for 
monitoring redundancy
• MnT Failover: Manual failover between 
monitoring nodes
• PSN HA: Deployment of multiple PSNs behind a 
load balancer or it can be configured on newer 
IOS versions.
• PSN Node Groups: Utilized to enable session 
failover for URL redirected issue

ISE Configuration : Policy Sets
Policy sets (both network access and 
device administration sets) enable you to 
logically group authentication and 
authorization policies within the same set. 
You can have several policy sets based on 
an area, location, access type and so on.
Policy sets are configured hierarchically, 
where the rule on the top level of the policy 
set, which can be viewed from the Policy set 
table, applies to the entire set and is matched 
before the rules for the rest of the policies and 
exceptions. Thereafter, rules of the set are 
applied in this order:
POLICY SETS
Authentication Policy 
Authorization policy – 
Local Exception 
Authorization policy – 
Global Exception
Authorization policy

What are conditions?
Simple Conditions Compound 
Conditions

authentication requests before applying the

policies

ISE Configuration : Policy Sets - Conditions 
SIMPLE
COMPOUND
A simple condition is a single logical test that evaluates one 
single attribute from the authentication request
A compound condition is a combination of two or more 
simple conditions using the logical operations ( AND/ OR ) to 
create more granular policy logic
